The server icon is an icon displayed to players through the multiplayer server browser.

It looks something like this:  
![Glowstone server icon](http://i.imgur.com/jXN0eJW.png)

You can have one too! Just put a 64x64 PNG image named `server-icon.png` into the Glowstone `config` folder.

If you are importing your server from a Vanilla/Spigot server, the `server-icon.png` will be copied automatically to the `config` folder.
