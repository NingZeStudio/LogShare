In general, Glowstone should have compatibility with all plugins that only use Bukkit calls, although features may not be implemented in Glowstone, yet.

Soon, you will be able to vote on plugins you want to work with Glowstone and find out workarounds through the Glowstone website, powered by Shine.

In the meantime, you can view a plugin compatibility table [on Airtable](https://airtable.com/shrJ8ValYIyktzbLn).
