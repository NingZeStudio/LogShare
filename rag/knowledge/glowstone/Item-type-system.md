Items and blocks IDs are registered in the constants system, using the [ItemIds class](https://github.com/GlowstoneMC/Glowstone/blob/master/src/main/java/net/glowstone/constants/ItemIds.java).

If additional functionality is required for an item or block, it is registered in the [Item Table class](https://github.com/GlowstoneMC/Glowstone/blob/master/src/main/java/net/glowstone/block/ItemTable.java). Classes that are registered to add additional functionality to items are in the [net.glowstone.block.itemtype package](https://github.com/GlowstoneMC/Glowstone/tree/master/src/main/java/net/glowstone/block/itemtype), and those for blocks are in the [net.glowstone.block.blocktype package](https://github.com/GlowstoneMC/Glowstone/tree/master/src/main/java/net/glowstone/block/blocktype).
