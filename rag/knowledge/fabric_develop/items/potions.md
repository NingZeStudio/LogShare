# 药水

药水是能为实体提供效果的消耗品。 玩家可以使用酿造台酿造药水，或者从其他游戏机制中以物品形式获取。

## 自定义药水

和物品和方块一样，药水需要注册。

## 准备你的药水 ID 类

如果你已经完成了创建你的第一个物品页面，那么这个过程对你来说会非常熟悉——你需要创建类来保存你的 `Potion` 的标识符，这些标识符存储为 `ResourceKey`。

这些对药水的引用用于生成药水标签的数据。

你可以将此方法放在一个名为 `ModPotionIds` 的类中（或者你想给类起什么名字都行）。

Mojang对药水也是这么做的！ 参考 `PotionIds` 类来获取灵感。
