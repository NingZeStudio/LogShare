# FCL / Android 专项：内存与进程被杀

## 签名 (Signature)

- 游戏加载到一半直接消失，latest.log 无异常结尾
- FCL 弹"游戏已停止/崩溃"但无 crash-report 生成
- `OutOfMemoryError`（heap/native）
- Android 低内存时系统杀后台：日志出现进程死亡但无 Java 栈

## 背景

手机物理内存普遍 6~16G，但要同时喂：Android 系统、启动器 App、JVM 堆、GPU 驱动占用。FCL 版本设置里有自动分配开关，默认按设备内存给上限。

## 排查顺序

1. **先看分配**：版本设置 → 内存 → 开"自动分配"；手动值别超过 设备总内存 × 0.5。
2. 后台别挂大应用（微信/浏览器占 1~2G）。
3. 大整合包（200+ Mod）：Metaspace 也吃几百 MB，堆外开销比 PC 感知更明显。
4. 反复在"加载资源阶段"死：加 `-Xmx` 前先确认是不是系统级 OOM——看 `/proc/meminfo` 可用值。

## 与 PC 的差异点

| 项 | PC | Android/FCL |
|---|---|---|
| OOM 表现 | hs_err 或 Java 异常 | 进程静默被杀居多 |
| 堆建议 | 总内存×0.6 | 总内存×0.4~0.5 |
| Swap | 通常有 | 通常无，OOM 更脆 |

## 置信度线索

- **确定**：无任何日志结尾 + 分配值 > 物理内存一半。
- **排除**：有完整 crash-report 的都不算这类——那是 JVM 内异常，走对应模式卡。
