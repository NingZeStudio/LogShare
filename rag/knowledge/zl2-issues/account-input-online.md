# ZL2 账户 / 输入 / 联机实战案例

## 账户体系

### 离线账户限制（ZL2 特有）★
- **2.4.0 起强制微软登录才能使用启动器**（#1048 #1067）
- **绕过方法**：在启动器根目录创建名为 `circumventLimit` 的空文件，离线账户即可用（#1124）
- 官方立场：不做破解账户支持（#1075）

### 微软登录失败
- **"IP blocked" 报错潮**（2026-06~07）：微软/Xbox 服务器侧问题，非启动器 bug，等恢复或换网（#1648 #1596 #1547 #1398）
- 中国区登录失败：疑似验证接口更新未跟进（#1372）；官方文档 [zalithlauncher.cn/docs/help/auth_server](https://www.zalithlauncher.cn/docs/help/auth_server.html)（#620）
- 卡在登录页不动：多试几次会自动继续（#436）
- 同名账户冲突：微软 + authlib-injector 同名无法共存已修（#229）

## 输入与触控

### 输入法架构演进
- 旧"实时模式/发送模式"已在最新开发版**整体移除**（#906）
- "简单模式"计划重做：重新引入 ZL1 的输入方式，解决手写选字框、实体键盘、语音输入兼容（#759）
- 实体键盘关不掉输入法 → 已修（#956 #942）；输入状态实时发给游戏但拿不到游戏内文本状态是根本局限，"发送按钮"方案缓解（#589）
- 输入法卡键 = mesa 系列 Mod 老问题，PC 端也有，不用输入法就没事（#1027）

### 触控
- **荣耀游戏管家劫持触控** → 移出游戏管家+重启（#1521，详见 mod-and-launcher.md）
- 物理鼠标转向方向错误（#1530 open）；触控笔悬停视作鼠标悬停已做（#713）
- 降低分辨率后快捷栏点击位置错位（#1271）
- 点击模式鼠标穿透"带动鼠标"控件（#755）

### 控制布局
- **摇杆不是布局控件**：因组件集成难度大，采用独立摇杆实现（#397 MovTery 说明）→ FCL 式"摇杆进布局/多摇杆切换"长期需求（#1014 #1523 open）
- 按键重叠时上层优先响应（#261）；布局编辑测试模式（#238）、游戏内直接改布局（#203）均已实现
- 手柄视角流畅度优化需求（#1664 open）；手柄 DPAD 映射 bug（#812）
- Key Binding Patch 拖累 options.txt 见 mod-and-launcher.md

### DeX / 外接
Samsung DeX 上游戏启动后启动器悬浮层不消失 → SurfaceView 后端检测不了游戏画面，加了手动关闭按钮（#1492）

## 联机（Terracotta / EasyTier）

- **架构**：陶瓦联机核心内置 EasyTier，但**未开启中转服务器**，不能加入个人 EasyTier 网络（#1211）
- **非中国地区不提供保证**——官方明确立场（#1553）
- Guest 进不了房间（Cannot find scaffolding server / PingHostFail）：常见于版本不齐（Terracotta/EasyTier 版本都要对上）（#1486）
- Terracotta 更新机制：commit 171be82 起（#622）
- 存档同步/迁移到公共目录是长期需求（Android/data 受限背景下）（#1696 #1697）

## 存档与目录权限

- **新版 Android 权限收紧**：`Android/data/<pkg>/files/.minecraft/saves` 文件管理器不可见/不可拷 → shc0743 给了代码级分析；迁移到公有目录是方向（#1376 #1696）
- 导出世界存档已实现（#663）；世界备份功能（#259）
- 26.1+ 新存档格式识别问题（#1352，关联 #1346）
- 创建世界时选数据包：受限于 ZLNativeInvoker 的文件分享机制（#778）
