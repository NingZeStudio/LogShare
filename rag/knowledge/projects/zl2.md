**Zalith Launcher 2** 是一个全新设计、面向 **Android 设备** 的 Minecraft: Java Edition 启动器。项目使用 PojavLauncher 作为启动核心，采用 **Jetpack Compose** 与 **Material Design 3** 构建现代化 UI 体验。

该项目与 ZalithLauncher 属于两个完全不同的项目

“Minecraft”及“我的世界”是 _Microsoft Corporation_ 和 _Mojang Synergies AB_ 的注册商标。ZalithLauncher 与 Microsoft、Mojang 或网易公司无任何从属或合作关系。
