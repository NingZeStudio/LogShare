# Minecraft 版本与运行环境要求速查

文档更新日期：2026-09-23。本表只保留与排障相关的版本段及其 Java / 图形运行环境要求；Classic / Indev / Infdev / Beta 与 1.0–1.15 的历史流水已移除（对崩溃诊断无增量信息，需要时查 Minecraft Wiki）。新增方块与生物等百科性内容一并裁去，只留机制与技术变更。

## 版本与 Java 运行环境要求

| 版本 | Java 要求 | 说明 |
|------|-----------|------|
| 1.9.3 起 | Java 8 Update 60 以上 | 1.9.3 废弃 Java 7 兼容 |
| 1.19.4 起 | Java 17 | 1.19.4 强制升级 Java 17，GC 性能提升 |
| 26.1 起 | Java 25 | 26.1 强制 Java 25 运行环境 |

低于对应 Java 版本的典型报错：`UnsupportedClassVersionError`（class 文件版本高于运行时）、`java.lang.NoSuchMethodError`（前置/模组按新版 API 编译）。

## 图形与渲染要求

| 版本 | 要求 |
|------|------|
| 1.21.9 起 | 服务端 OpenGL 3.3 硬性要求 |
| 26.2 | 实验性 Vulkan 渲染支持与图形 API 切换选项 |
| 26.3 | 窗口/输入后端从 GLFW 切换至 SDL3（原生支持 Wayland，无边框全屏默认，键位绑定改为物理按键扫描码）；着色器编译统一为 ShaderC（OpenGL/Vulkan 一致）；新增 OIT（顺序无关透明度）渲染管线 |
