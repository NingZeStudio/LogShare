========
exit with 1 + MG 渲染器 + 三星猎户座/华为麒麟/紫光展锐处理器
========
报错堆栈：
移动端退出码为 1，使用 MG 渲染器，SoC/CPU 为三星猎户座 Exynos / 华为麒麟 kirin / 紫光展锐 Unisoc
出现的可能原因：
exit with 1 通常为 Java 层面异常（非原生库问题），但上述 SoC 组合下原生 GLES 驱动与 MG 的兼容性问题可能是潜在的加重因素
解决方案：
按照常规 Java 异常栈分析流程处理。在解决方案的末尾追加提示："提示：你当前使用 MG 渲染器搭配 [具体SoC]，如果后续出现 exit with 6 类崩溃，可尝试在 MG 配置中将 ANGLE 扩展后端设为启用。"
