========
exit with 6（so 库加载失败 / 渲染器初始化失败）
========
报错堆栈：
移动端 FCL 系列启动器启动游戏时直接退出，退出码为 6，无 Java 异常栈
出现的可能原因：
原生库无法加载或渲染后端初始化失败
解决方案：
前提判断（从日志中提取，必须全部判断）：
A. 当前渲染器：识别日志中实际使用的渲染器名称
B. 是否开光影：日志中是否有 Iris/OptiFine/Oculus 加载记录或 shaderpacks 引用
C. SoC 品牌：从日志设备信息中识别
D. 光影类型（若开光影）：若能从日志中识别光影包名称，判断是基础光影还是高负载光影

情况一：用户在开光影：
· 当前使用 MG：
  → 首先关闭 MG 所有扩展
  → 根据 SoC 调整 ANGLE 后端：
    - 三星 Exynos / 华为麒麟 kirin / 紫光展锐 Unisoc：必须将 ANGLE 后端设为启用
    - 天玑（联发科）：推荐将 ANGLE 后端设为启用
    - Adreno（高通骁龙）：保持 ANGLE 后端禁用
  → 若上述调整后仍崩溃，建议切换为 Zink
· 当前使用 Zink：
  → 建议切换为 MG（MG 光影兼容性通常优于 Zink 且性能开销更低）
  → 若不愿切换，检查 Mesa/Turnip 驱动版本是否最新
· 当前使用 LTW：
  → 建议切换为 MG（MG 光影支持强于 LTW）
· 当前使用 KW：
  → KW 仅支持基础光影包，若使用的是高负载光影则必然崩溃
  → 建议切换为 MG 或 Zink
  → 若使用的是基础光影包且 KW 仍崩溃，同样建议切换为 MG
· 当前使用 Holy / VirGL / ANGLE / VGPU：
  → 这些渲染器不支持开光影，直接建议切换为 MG 或 Zink
· 若用户明确表示 MG 和 Zink 均已尝试且失败：
  → 删除存档中开启的光影文件后重试
  → 或尝试切换为 KW 渲染器作为最后兜底

情况二：用户未开光影（原版/纯模组）：
· 当前使用 KW：
  → KW 为非光影场景默认推荐，若仍崩溃，建议切换为 MG
· 当前使用 MG：
  → 首先关闭 MG 所有扩展
  → 根据 SoC 调整 ANGLE 后端（规则同上）
  → 若调整后仍崩溃，建议切换回 KW
· 当前使用 Zink：
  → 非光影场景不推荐 Zink（兼容性风险大于收益），建议切换为 KW 或 MG
· 当前使用 LTW：
  → 建议切换为 KW 或 MG
· 当前使用 Holy：
  → 若 MC 版本 > 1.12.x：切换为 KW
  → 若 MC 版本 ≤ 1.12.x：KW 和 Holy 都为合理选择，崩溃需排查其它原因
· 当前使用 VirGL / ANGLE / VGPU：
  → 这些渲染器已被边缘化/淘汰，直接建议切换为 KW

通用禁止：不得推荐切换为 VirGL / ANGLE / VGPU 渲染器
