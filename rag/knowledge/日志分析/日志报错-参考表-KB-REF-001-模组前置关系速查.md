========
模组前置关系速查表
========
报错堆栈：
不适用（通用参考）
出现的可能原因：
模组缺少必需前置导致启动或运行崩溃
解决方案：
常见模组前置对照：
- Cloth Config → Fabric API
- Sodium / Lithium / Iris → Fabric API（Iris 额外需要 Sodium）
- Create → Flywheel, KubeJS（可选）
- Inventory Profiles Next (IPN) → libIPN, fabric-language-kotlin
- Replay Mod → Fabric API（可选）
- Jade / Hwyla / WTHIT → Fabric API / Forge
- Xaero's Minimap / World Map → Fabric API / Forge
- Complementary Shaders → Iris
- Complementary Reimagined → Iris
- Create Mod (Fabric) → Fabric API, Flywheel, Reach Entity Attributes
- Litematica → Fabric API, MaLiLib
- MiniHUD → Fabric API, MaLiLib
- Tweakeroo → Fabric API, MaLiLib
- Distant Horizons → Fabric API / Forge
- Mod Menu → Fabric API
- AppleSkin → Fabric API / Forge
- Architectury API → 无（但大量模组依赖它）
- KubeJS → Rhino, Architectury API
- Rhino → 无
- Waystones → Fabric API / Forge
- Inspecio → Fabric API
- Better Third Person → Fabric API（可选）
