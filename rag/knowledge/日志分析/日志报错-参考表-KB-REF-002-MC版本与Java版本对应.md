========
Minecraft 版本与 Java 版本对应关系
========
报错堆栈：
不适用（通用参考）
出现的可能原因：
Java 版本与 MC 版本不匹配导致启动崩溃或运行异常
解决方案：
MC 版本与 Java 版本对应：
- MC 26.1 及以后 → 最低 Java 25，推荐 Java 25
- MC 1.20.5 ~ 1.21.11 → 最低 Java 21，推荐 Java 21 (Eclipse Temurin)
- MC 1.18.2 ~ 1.20.4 → 最低 Java 17，推荐 Java 17 (Eclipse Temurin)
- MC 1.17 ~ 1.17.1 → 最低 Java 16，推荐 Java 17 (Eclipse Temurin)
- MC 1.8 ~ 1.16.5 → 最低 Java 8，推荐 Java 8
- MC 1.7.10 及更早 → Java 7/8，推荐 Java 8
注：分析日志时若发现 Java 版本不匹配，必须在解决方案中首先指出
